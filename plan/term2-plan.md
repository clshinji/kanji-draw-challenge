## Phase 0: 経済システムの基盤（コイン・素材の獲得）

### Task 0-1: コイン獲得の仕組み

- **概要**: 漢字練習の結果に応じてコインを獲得できるようにする
- **報酬設計**:
  - ★3: 10コイン
  - ★2: 5コイン
  - ★1: 2コイン
  - 連続正解ボーナス: コンボ数 × 1コイン（最大+5）
  - ストリークボーナス（2日以上連続）: +3コイン
- **対象ファイル**:
  - `js/game-state.js`: コイン残高の管理、獲得ロジック追加
  - `js/feedback.js`: コイン獲得演出の追加
  - `index.html`: コイン表示UI
  - `css/style.css`: コイン表示のスタイル
- **実装詳細**:
  - `gameState.coins` をlocalStorageに永続化
  - `onKanjiPracticed()` の返り値に `earnedCoins` を追加
  - ホーム画面ヘッダーにコイン残高を常時表示
  - フィードバック画面にコイン獲得アニメーション（XP表示と同様の演出）

### Task 0-2: 素材（鉱石）獲得の仕組み

- **概要**: 練習結果に応じてランダムに素材（鉱石）をドロップする
- **素材の種類**（マイクラ風）:
  - 石（いし）: ドロップ率 40%
  - 鉄（てつ）: ドロップ率 25%
  - 金（きん）: ドロップ率 15%
  - ダイヤ: ドロップ率 5%
  - ドロップなし: 15%
- **ドロップ条件**: ★2以上でドロップ判定が発生。★3は判定を2回行う
- **対象ファイル**:
  - `js/game-state.js`: 素材インベントリの管理、ドロップロジック
  - `js/feedback.js`: 素材獲得演出（鉱石アイコン + 名前のポップアップ）
  - `index.html`: インベントリ表示UI（設定画面 or ホーム画面）
  - `css/style.css`: 素材アイコンのスタイル
  - `images/`: 鉱石のドット絵アイコン（4種）
- **実装詳細**:
  - `gameState.materials = { stone: 0, iron: 0, gold: 0, diamond: 0 }` をlocalStorageに永続化
  - `onKanjiPracticed()` の返り値に `droppedMaterial` を追加
  - 素材獲得時はマイクラの採掘音を彷彿とさせるドット絵アニメーションで演出

## Phase 1: ショップ機能

### Task 1-1: ショップ画面の実装

- **概要**: コインで庭の装飾アイテムを購入できるショップ画面を追加
- **アンロック条件**: レベル3（`xpRequired: 150`）以上で解放
- **ショップへのアクセス**: ホーム画面に「ショップ」ボタンを追加（アンロック前はロックアイコン表示）
- **対象ファイル**:
  - `js/shop.js`（新規）: ショップロジック、商品定義、購入処理
  - `js/app.js`: ショップ画面への遷移、アンロック判定
  - `index.html`: `#screen-shop` 画面の追加
  - `css/style.css`: ショップ画面のスタイル
- **実装詳細**:
  - 商品カテゴリ: 「おにわアイテム」（庭に配置できる装飾）
  - 商品データは `shop.js` 内に定数として定義
  - 購入時にコイン残高チェック → 残高不足時はマスコットが「コインがたりないよ〜」
  - 購入完了時にアイテムがインベントリに追加される

### Task 1-2: 素材の換金機能

- **概要**: 不要な素材をショップで売却してコインに換金できる
- **換金レート**:
  - 石: 2コイン
  - 鉄: 5コイン
  - 金: 15コイン
  - ダイヤ: 50コイン
- **対象ファイル**:
  - `js/shop.js`: 換金ロジック追加
  - `index.html`: 換金UIをショップ画面内に設置
- **実装詳細**:
  - ショップ画面内に「もちもの」タブを設け、素材の一覧と「うる」ボタンを表示
  - 一括売却は不要（1個ずつ売却で十分）

## Phase 2: 庭機能の拡張

### Task 2-1: 庭の詳細画面

- **概要**: ホーム画面の庭プレビューをタップすると、庭の全体が見られる詳細画面に遷移
- **対象ファイル**:
  - `js/garden.js`: 詳細画面のレンダリングロジック追加
  - `js/app.js`: 庭詳細画面への遷移
  - `index.html`: `#screen-garden` 画面の追加
  - `css/style.css`: 庭詳細画面のスタイル
- **実装詳細**:
  - 全漢字のプロット（成長段階）を一覧表示
  - カテゴリ別にエリアを分けて表示
  - 各プロットをタップすると、その漢字の練習状況（星数、練習回数）を確認できる

### Task 2-2: 庭の装飾アイテム配置

- **概要**: ショップで購入した装飾アイテムを庭に配置できるようにする
- **装飾アイテム例**:
  - 柵（さく）: 10コイン
  - 花壇（かだん）: 20コイン
  - 池（いけ）: 50コイン
  - たいまつ: 30コイン
  - 看板（かんばん）: 15コイン
- **対象ファイル**:
  - `js/garden.js`: アイテム配置ロジック、配置データの永続化
  - `js/game-state.js`: 配置データの保存・読み込み
  - `index.html`: 配置UIの追加
  - `css/style.css`: 装飾アイテムのスタイル
  - `images/`: 装飾アイテムのドット絵（5種）
- **実装詳細**:
  - 庭詳細画面で「もようがえ」モードに切り替え → グリッド上にアイテムをドラッグ配置
  - 配置データは `gameState.gardenDecorations` としてlocalStorageに永続化
  - シンプルなグリッドベース配置（自由配置は複雑すぎるため避ける）

## Phase 3: クラウド同期の拡張

### Task 3-1: 新規データのクラウド同期対応

- **概要**: Term 2で追加されたデータ（コイン、素材、装飾配置）をクラウド同期に含める
- **対象ファイル**:
  - `js/cloud-sync.js`: 同期ペイロードに新規フィールドを追加
  - `infra/lambda/index.mjs`: バリデーションの更新（必要に応じて）
- **実装詳細**:
  - 既存の `{ version, gameState, progress }` 構造を維持し、`gameState` 内に新フィールドを含める
  - 旧バージョンのデータとの後方互換性を保つ（新フィールドが無い場合はデフォルト値で補完）

## 検証方法

- iPadのSafariで全機能をテストプレイ
- 練習完了時にコインと素材が正しく獲得できることを確認
- ショップで商品の購入・素材の換金が正しく動作することを確認
- 庭の詳細画面で全プロットが正しく表示されることを確認
- 庭に装飾アイテムを配置・保存・再読み込みできることを確認
- クラウド同期で新規データ（コイン・素材・装飾）が正しく同期されることを確認
- 旧バージョンのセーブデータとの後方互換性を確認
